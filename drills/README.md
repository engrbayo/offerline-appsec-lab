# Code-reading drills

Each file has 1 to 3 security bugs. Time yourself: 3 minutes per file, out
loud, the way you would in the interview:

1. What does this code do, in one sentence?
2. Where does untrusted input enter?
3. What's the bug, what can an attacker do with it, and how bad is it here?
4. What's the fix, and what control would stop it recurring (rule, test, framework default)?

Answers are in ANSWERS.md. Don't open it until you've said your answer aloud.
